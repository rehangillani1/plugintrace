# PluginTrace

Source of [plugintrace.com](https://plugintrace.com): independent lab tests of free WordPress.org plugins. What they send
from your server, what they load in visitors' browsers, the cookies they set, whether they break page caching and what
they leave behind when you delete them, with the code that does it.

- **Reports:** `plugins/<slug>/`
- **Open data:** `data/<slug>.json`, indexed in [`data/index.json`](data/index.json), licensed
  [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)
- **Method:** [plugintrace.com/method](https://plugintrace.com/method/)

## Corrections

Plugin author and a report is wrong or out of date? [Open an issue](https://github.com/rehangillani1/plugintrace/issues/new)
with the plugin and what you think is wrong. We re-run the test and note the correction on the report.
